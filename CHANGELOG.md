# Changelog

## [0.05] - 2026-07-14

### Добавлено
- Dividend Bot — планировщик дивидендных сигналов (`dividend_bot/`)
- Ежедневное сканирование топ-100 акций MOEX по капитализации (MOEX ISS API, без авторизации)
- Дивидендная стратегия T-7 → T-1: покупка за 7 торговых дней до отсечки, продажа за 1 день до отсечки
- Telegram-уведомления: новые дивидендные события, напоминание о дне входа, напоминание о дне выхода
- Контекст рынка в каждом сообщении: IMOEX с MA50 и MA200
- Расчёт позиции акции в 52-недельном диапазоне (High/Low)
- Расчёт P&L от входа в день напоминания о выходе
- Дедупликация сигналов через SQLite (`dividend_bot.db`)
- Планировщик APScheduler: запуск по будням в 07:00 UTC (10:00 МСК)
- Запуск вручную через флаг `--now`

## [0.04] - 2026-07-14

### Добавлено
- График «Портфель · нереализованный P&L по позициям»: горизонтальные бары по каждой акции, цвет зависит от знака P&L, тултип с полным названием, стоимостью и доходностью
- График «Доходность акций по месяцам»: мультилинейный, топ-5 позиций по стоимости, ценовая доходность % за каждый месяц из дневных свечей T-Invest API
- Эндпоинты `/portfolio-snapshot` и `/portfolio-monthly`
- Кэш инструментов `_instrument_cache` для повторного использования между запросами

## [0.03] - 2026-07-14

### Добавлено
- Годовой график «Заработок по месяцам (последний год)»: столбцы заработка и заработка за вычетом налога 13%, линия доходности (%)
- Расчёт доходности по методу Modified Dietz с учётом взвешенных по времени пополнений и снятий
- Новый endpoint `/yearly-chart-data` — возвращает 12 месяцев данных: earnings, earnings_net, return_pct
- Смешанный Chart.js (bar + line) с двумя осями Y: рубли слева, проценты справа

## [0.02] - 2026-07-13

### Добавлено
- Интеграция с T-Invest API (Т-Банк): синхронизация текущего баланса и операций
- Тогл «Ручной ввод / Автосинхронизация» с сохранением режима в localStorage
- Импорт операций за год одним запуском (import_operations.py)
- Итоговые суммы пополнений и снятий под таблицей операций
- Выходные дни на графике отображаются бледнее будних
- Исправлен расчёт заработка: транзакции на дату первой записи баланса теперь учитываются корректно
- Исправлена блокировка SQLite (WAL-режим + timeout)

## [0.01] - 2026-07-13

### Добавлено
- Ручной ввод баланса счёта по датам
- Запись снятий и пополнений с типом и комментарием
- Расчёт реального заработка: пополнения и снятия не искажают результат
- Учёт только торговых дней (пн–пт) при расчёте дневного заработка
- Статистика за неделю и месяц с учётом налога 13%
- Карточки: заработано за всё время, всего выведено, всего пополнено
- График заработка по дням за последние 30 дней
- Калькулятор комиссии при снятии (поле в форме снятия)
- История балансов и история операций
- Подготовка к интеграции с T-Invest API (config.py, .claudeignore, .gitignore)
