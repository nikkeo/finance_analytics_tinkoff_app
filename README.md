# Finance Analytics Tinkoff App

Веб-приложение для отслеживания реального заработка на брокерском счёте.

## Что делает

- Записывает баланс счёта вручную или через синхронизацию с T-Invest API
- Считает реальный заработок — пополнения и снятия не искажают результат
- Показывает статистику за неделю, месяц и за всё время
- Строит график заработка по дням за последние 30 дней
- Учитывает только торговые дни (пн–пт)
- Позволяет записывать снятия и пополнения с расчётом комиссии

## Стек

- Python, Flask, SQLite
- Chart.js, Bootstrap 5
