# Finance Analytics Tinkoff App

Веб-приложение для отслеживания реального заработка на брокерском счёте Т-Инвестиций + Telegram-бот дивидендных сигналов.

## Finance Tracker (веб-приложение)

- Записывает баланс счёта вручную или синхронизирует автоматически через T-Invest API
- Импортирует операции (пополнения и снятия) за последний год из брокерского счёта
- Считает реальный заработок — пополнения и снятия не искажают результат
- Учитывает только торговые дни (пн–пт) при расчёте дневного заработка
- Показывает статистику за неделю, месяц и за всё время с учётом налога 13%
- График заработка по дням за последние 30 дней
- Годовой график с заработком, заработком после налога и доходностью по методу Modified Dietz
- График нереализованного P&L по позициям портфеля (из T-Invest API)
- График ценовой доходности топ-5 акций по месяцам (из свечей T-Invest API)
- Записывает снятия и пополнения вручную с расчётом комиссии

## Dividend Bot (`dividend_bot/`)

- Ежедневно сканирует топ-100 акций MOEX по капитализации (MOEX ISS API)
- Реализует дивидендную стратегию T-7 → T-1: вход за 7 торговых дней до отсечки, выход за 1 день
- Отправляет Telegram-уведомления: новые дивидендные события, напоминания о входе и выходе
- В каждом сообщении — контекст рынка (IMOEX, MA50, MA200) и позиция акции в 52w диапазоне
- Дедупликация сигналов через SQLite, хранение цены входа для расчёта P&L
- Запуск по расписанию (будни 07:00 UTC) или вручную: `python main.py --now`

## Стек

- Python, Flask, SQLite
- Chart.js, Bootstrap 5
- T-Invest REST API (Т-Банк)
- MOEX ISS API
- APScheduler, python-telegram-bot
